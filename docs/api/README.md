# API

API version: `v1`.

Base namespace: `/api/v1`

OpenAPI: 3.x
Swagger UI target: `/api/docs`

Initial endpoint families from the PRD include authentication, user, wallet/history, rewards, missions, watch, withdrawals, account deletion and Duitku/Xendit webhooks.

The API contract is the communication source between backend, Android and Admin. Admin endpoints require authorization and permission checks.
